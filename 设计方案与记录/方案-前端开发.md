# 方案-前端开发

## 一、目标

基于 Vue.js 3 开发图书馆管理系统前端，**避免常见的 AI 风通用模板**，打造一个视觉有特点、功能严谨、用户友好的真实图书馆管理系统。

---

## 二、设计理念：远离"AI风"

### AI 风的典型特征（全部规避）

| AI 风特征 | 我们的替代方案 |
|-----------|---------------|
| Element Plus / Ant Design 默认蓝白色调 | **暖木色 + 学术绿**：图书馆实木书架、旧书纸的暖色调 |
| 通用 sidebar + header 布局 | **顶部横向导航 + 面包屑**：像真实图书馆的楼层导视牌 |
| 千篇一律的卡片列表 | **书脊式列表**：图书列表模拟书架上的书脊效果 |
| 默认表单样式 | **借书证风格**：借阅操作设计为"刷卡"式交互 |
| 冷冰冰的数据表格 | **手帐风格统计**：统计数据用轻量手绘感图表展示 |
| 无个性的登录页 | **借书证+藏书票**：登录页模拟翻开一本老书的扉页 |

### 配色方案：旧书馆

```
主色调：   #5D4037  深棕木色  （导航、标题）
辅助色：   #2E7D32  学术绿    （成功状态、按钮）
背景色：   #FAF3E0  古董白/书页色 （页面背景）
卡片色：   #FFF8F0  暖白      （卡片、表格）
强调色：   #C62828  朱红印章色 （警告、逾期标记）
文字色：   #3E2723  深褐      （正文）
次要文字： #8D6E63  浅棕      （提示文字）
边框色：   #D7CCC8  淡木色    （分隔线）
```

### 字体选择

- 标题：`Georgia, 'Noto Serif SC', serif`（衬线体，古典书香感）
- 正文：`'PingFang SC', 'Microsoft YaHei', sans-serif`
- 数字/表格：`'SF Mono', 'Consolas', monospace`

## 三、技术栈

| 层 | 技术 | 用途 |
|----|------|------|
| 框架 | Vue 3 (Composition API) | 组件化开发 |
| 构建 | Vite | 快速开发构建 |
| 路由 | Vue Router 4 | SPA 路由 |
| 状态 | Pinia | 全局状态管理（用户信息、token） |
| HTTP | axios | API 请求 + 拦截器 |
| 样式 | **纯 CSS（BEM 命名）** | 自定义风格，拒绝组件库默认样式 |
| 图表 | Chart.js (vue-chartjs) | 轻量统计图表 |
| 图标 | 自定义 SVG / 简单 Unicode | 避免 Font Awesome 的"AI感" |

> **刻意不使用** Element Plus / Ant Design / Vuetify 等组件库——它们会导致界面同质化。

## 五、各页面详细设计

### 5.1 登录页 `/login`

**设计灵感**：翻开一本旧书的扉页，左侧是"藏书票"，右侧是登录表单。

- 整体背景：暖色调渐变（模拟旧书页质感）
- 左侧：一张藏书票风格的插图（图书馆建筑轮廓 + "館"字印章），附带一句名言
- 右侧：借书证风格的登录卡片（米白色，微妙阴影，圆角）
  - 用户名输入框（前面有个小图标：人像轮廓）
  - 密码输入框
  - 验证码输入 + 验证码图片（点击刷新）
  - 登录按钮（深木色，#5D4037）
- 底部：手写体风格的系统名称"高校图书借阅管理系统"

**功能**：
- 获取验证码 → 输入用户名/密码/验证码 → 登录 → 存储 JWT → 跳转
- 验证码点击刷新
- 登录失败提示

### 5.2 仪表盘 `/dashboard`

**设计灵感**：图书馆前台的登记台面，一览今日概况。

- 顶部：欢迎语 + 当前日期（像日历翻页效果）
- 四张概览卡片（木纹边框）：
  - 今日借出数量
  - 当前超期数量（红色强调）
  - 馆藏总量
  - 今日归还数量
- 下方两栏：
  - 左：最近借阅记录（简洁列表，5条）
  - 右：超期提醒（红色标记，带读者姓名和天数）
- 管理员/图书管理员额外可见：操作日志摘要

**角色差异**：
- admin/librarian：全量数据
- reader：仅显示自己的借阅状态、超期提醒

### 5.3 图书管理 `/books`

**设计灵感**：书架浏览体验。图书列表不是冷冰冰的表格，而是模拟书架上的书脊。

- 顶部搜索栏：一个横向的搜索条（像图书馆检索终端）
  - 关键词输入（搜索书名/作者/ISBN）
  - 分类下拉筛选
  - 价格范围（两个小输入框，中间一个横线）
  - 搜索按钮
- **书脊式列表**（特色）：
  - 每本书显示为一条横向"书脊"——不同分类用不同颜色左边框标识
  - 左侧：分类色条（计算机=蓝灰、数学=深绿、物理=紫、文学=暖橙）
  - 中间：书名（粗体）、作者、出版社
  - 右侧：可借数/总数、操作按钮（查看/编辑/删除）
  - 库存紧张（<3本）时显示橙色角标
- 右上角"新增图书"按钮
- 底部分页（简洁的页码数字）

**模糊搜索+范围查询**：
- 搜索防抖 300ms，实时向后端发请求
- URL query 参数同步（可分享搜索结果链接）

### 5.4 读者管理 `/readers`

**设计灵感**：借书证登记册。

- 搜索 + 类型筛选（学生/教师）
- 列表样式：每行像一个简化的"借书证"条目
  - 左侧：头像占位圆（根据读者类型不同颜色：学生=绿、教师=蓝）
  - 姓名 + 学工号
  - 院系
  - 当前借阅数 / 最大限额（进度条样式，临近限额变橙色）
  - 状态标签（正常/禁用）
  - 操作按钮

### 5.5 借书操作 `/borrow` ⭐核心页面

**设计灵感**：图书馆前台借书流程——"刷卡→扫书→确认"。

- 两步式流程设计（step-by-step）：
  - **第1步**：输入读者编号（像刷卡），回车查询 → 显示读者信息卡片（姓名/类型/当前借阅数/限额）
  - **第2步**：输入图书 ISBN（像扫描枪），回车查询 → 显示图书信息卡片（书名/作者/库存/封面占位）
  - **确认按钮**：大号的"确认借阅"按钮（深木色），点击后弹出确认框
- 成功：绿色提示 + 显示应还日期
- 失败：红色提示 + 具体原因（库存不足/达到限额/读者不存在）

### 5.6 还书操作 `/return`

- 输入借阅编号或扫描 ISBN + 读者编号
- 显示借阅详情
- 确认还书 → 自动计算并显示罚金（如有超期）
- 还书成功：显示"已归还"+"罚金 ¥X.XX"（如有）

### 5.7 超期未还 `/overdue`

**设计灵感**：催还通知单。

- 每条记录像一张"催还通知"：
  - ⚠️ 红色图标 + 超期天数（大字显示）
  - 读者信息（姓名+类型+院系）
  - 图书信息（书名+ISBN）
  - 借阅日期 → 应还日期（直观的时间线）
  - 预估罚金

### 5.8 统计报表 `/stats`

- 三个标签页切换：
  - **借阅热度榜**：图书借阅次数排行（横向条形图，书脊延伸效果）
  - **读者统计**：读者借阅量排名 + 罚金汇总
  - **月度趋势**：近12月罚金变化折线图
- 图表使用暖色调，与整体风格一致

### 5.9 罚金管理 `/fines`

- 当前罚金规则展示（X 元/天）
- 罚金规则修改（仅 admin）
- 按读者查看罚金明细

### 5.10 系统管理 `/admin/*`

- **操作日志**：时间倒序列表，支持按操作类型/表名筛选
- **备份管理**：备份记录列表 + "立即全量备份"/"立即差异备份"按钮
  - 备份成功后刷新列表

## 六、前端如何体现数据库+后端逻辑

| 数据库层 | 前端体现 |
|----------|---------|
| `books.available_copies` CHECK ≥0 | 借书时实时显示库存，库存为0时禁用操作 |
| `reader_types.max_borrow_count` | 读者详情显示"已借X/限额Y"进度条，接近限额时警示 |
| `borrow_records` CHECK（日期约束） | 日期选择器限制、归还日期≥借阅日期 |
| PK/FK 约束 | 重复ISBN/学号时后端返回400，前端红色提示 |
| `v_current_borrowings` 视图 | 仪表盘+读者详情实时展示 |
| `v_overdue_books` 视图 | 超期页面直接消费此视图数据 |
| `sp_get_reader_borrowings` | 读者详情页调用，展示当前借阅列表 |
| 触发器自动减库存 | 借书成功后前端实时刷新库存数字 |
| 触发器自动计罚金 | 还书后前端展示罚金弹窗 |
| `operation_logs` 审计日志 | 管理后台日志页面，支持筛选 |
| gs_encrypt_aes128 加密 | 管理员查看读者详情才解密显示联系方式 |

## 十、细节特色（反AI风清单）

1. **书脊色彩编码**：不同分类图书左边框颜色不同（计算机=蓝灰、数学=绿、物理=紫）
2. **借书流程两步式**："刷卡→扫书→确认"，模拟真实图书馆前台操作
3. **进度条式借阅限额**：读者已借数/限额用进度条展示，接近上限变为橙色
4. **催还通知样式**：超期记录模拟真实的"催还通知单"排版
5. **暖色调图表**：统计图表配色使用木色/暖色系，而非默认蓝
6. **手写感标注**：关键数字（超期天数、罚金金额）使用 Georgia 衬线字体突出
7. **禁用态友好**：库存为0时"借阅"按钮置灰+提示，而非报错
8. **错误信息人性化**："图书已全部借出，无法借阅"而非"error: available_copies <= 0"
9. **加载态有温度**：Loading 使用书本翻页动画，而非冷冰冰的转圈
10. **空状态引导**："书架上暂时没有这类书，试试其他分类？"而非"暂无数据"
