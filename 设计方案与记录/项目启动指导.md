# 高校图书借阅管理系统 — 项目启动指导

## 环境要求

| 组件 | 版本 | 用途 |
|------|------|------|
| Docker | 20.10+ | OpenGauss 数据库 |
| Python | 3.9+ | FastAPI 后端 |
| Node.js | 18+ | Vue 3 前端 |

---

## 快速启动（推荐）

### 方式一：一键启动脚本（Windows）

```powershell
# 双击运行或在终端执行
.\start_all.ps1
```

自动打开两个终端窗口：
- 后端：http://127.0.0.1:8000
- 前端：http://localhost:8084

> **⚠ 首次运行前**：需先完成以下「环境准备」和「数据库初始化」步骤。

### 方式二：手动启动

按顺序执行以下步骤。

---

## 一、环境准备

```bash
# 安装 Python 依赖（仅首次）
cd backend
pip install -r requirements.txt

# 安装前端依赖（仅首次）
cd frontend
npm install
```

---

## 二、启动数据库

```bash
docker run -d --name opengauss --privileged=true \
  -e GS_PASSWORD=Gauss123! -e GS_DB=library_db \
  -p 5432:5432 \
  enmotech/opengauss:5.0.0
```

等待 30 秒让数据库初始化完成。

> 端口冲突时改为 `-p 15432:5432`，同时改 `backend/config.py` 中的 `port`。

---

## 三、初始化数据库

```bash
cd backend
python sql/run_all.py      # 建表 + 索引 + 视图 + 触发器 + 种子数据
python sql/verify_all.py    # 验证（可选）
```

> **数据库脚本包含**：
> - 01_create_tables.sql — 8张表
> - 02_create_indexes.sql — 12个索引
> - 03_create_views.sql — 5个视图
> - 04_create_procedures.sql — 4个存储过程/函数
> - 05_create_triggers.sql — 5个触发器
> - 06_seed_data.sql — 种子数据（15本书、5位读者、6条借阅记录）
> - 07_borrow_applications.sql — 借阅申请表（申请→审批流程）

---

## 四、启动后端

```bash
# 方式A：使用启动脚本（自动清理端口）
.\start_backend.ps1

# 方式B：直接启动
cd backend
python -m uvicorn main:app --host 127.0.0.1 --port 8000 --reload
```

验证：浏览器打开 http://127.0.0.1:8000/docs 看 Swagger 页面。

## 五、启动前端

```bash
# 方式A：使用启动脚本
.\start_frontend.ps1

# 方式B：直接启动
cd frontend
npm run dev
```

浏览器打开 **http://localhost:8084**。

## 八、常见问题

### 端口 8000 被占用

```bash
netstat -ano | findstr ":8000"     # 找到 PID
taskkill //PID <PID> //F             # 终止进程
```

### 数据库连接失败

确认 Docker 在运行：`docker ps | grep opengauss`

### 前端页面空白 / 验证码不显示

F12 → Console 查看报错。通常原因：后端 8000 端口未启动。

### 重置数据库

```bash
docker exec -it opengauss gsql -U gaussdb -d postgres \
  -c "DROP DATABASE library_db; CREATE DATABASE library_db;"
cd backend && python sql/run_all.py
```
