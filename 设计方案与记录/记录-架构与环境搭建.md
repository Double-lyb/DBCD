### 技术架构示意图

```
┌──────────────┐     HTTP请求     ┌──────────────┐     SQL查询     ┌──────────────┐
│   Vue.js     │ ────────────────>│   FastAPI    │ ──────────────>│  OpenGauss   │
│   (前端)     │<──────────────── │   (后端)     │<────────────── │   (数据库)   │
│ localhost:8084│     JSON响应     │ localhost:8000│    查询结果    │ 127.0.0.1:5432│
└──────────────┘                  └──────────────┘                 └──────────────┘
```

### 通信流程

1. **前端 → 后端**：axios 发起 HTTP 请求，携带 JWT Token
2. **后端 → 数据库**：psycopg2 连接池执行 SQL 查询
3. **数据库 → 后端**：返回查询结果
4. **后端 → 前端**：FastAPI 自动序列化 JSON 响应
