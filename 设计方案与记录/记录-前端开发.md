### 技术点对照

| 要求 | 实现 |
|------|------|
| 验证码登录 | LoginView.vue，点击刷新验证码 |
| JWT 存储 | Pinia auth store，localStorage 持久化 |
| 路由守卫 | router/index.js，未登录重定向到 /login |
| 角色差异化 | DashboardView 根据 role 显示不同内容 |
| 模糊搜索 | SearchBar.vue + debounce 300ms |
| 范围查询 | 价格区间输入（price_min/price_max） |
| 书脊式列表 | BookSpine.vue，分类色条标识 |
| 进度条限额 | ReaderListView，接近限额变橙色 |
| 催还通知样式 | OverdueView，红色图标 + 大字超期天数 |
| 图表统计 | StatsView，Chart.js 暖色调图表 |
