# 方案-后端开发

## 目标

基于 FastAPI + psycopg2 搭建后端 API，连接 OpenGauss `library_db`，实现图书借阅管理系统的全部业务接口。

## 四、安全机制实现计划

| # | 机制 | 实现 |
|---|------|------|
| 1 | 验证码 | `/api/auth/captcha` 生成，存入 session/Redis，登录时校验 |
| 2 | RBAC | JWT payload 含 `role`，每个路由用 Depends 检查角色权限 |
| 3 | 密码密文 | `bcrypt.hashpw()` → 存入 `password_hash`，验证用 `bcrypt.checkpw()` |
| 4 | 敏感数据加密 | `readers.phone/email` 写入时调用 `gs_encrypt_aes128(data, key)`，读取时 `gs_decrypt_aes128()` |
| 5 | 安全视图 | `v_current_borrowings` 不暴露 phone/email/password；reader 角色只能看自己数据 |
| 6 | 安全触发器 | `trg_operation_log` 审计 + `trg_prevent_book_delete` 拦截（数据库层已就绪） |

## 五、关键代码示例

### 数据库连接（database.py）

```python
import psycopg2
from psycopg2 import pool
from config import DB_CONFIG

connection_pool = pool.SimpleConnectionPool(
    minconn=2, maxconn=10, **DB_CONFIG
)

def get_db():
    conn = connection_pool.getconn()
    try:
        yield conn
    finally:
        connection_pool.putconn(conn)
```

### 借书接口要点

```
1. 校验 JWT（role: admin/librarian）
2. 校验读者是否存在、状态是否 active
3. 校验图书是否存在、available_copies > 0
4. INSERT INTO borrow_records — 触发器自动：
   - 校验限额（fn_can_borrow）
   - 计算 due_date
   - 减少 available_copies
5. 返回借阅记录
```

### 还书接口要点

```
1. UPDATE borrow_records SET return_date = CURRENT_DATE — 触发器自动：
   - 计算罚金
   - 增加 available_copies
2. 返回罚金信息
```

## 七、注意事项

1. **OpenGauss 加密**：`gs_encrypt_aes128(plaintext, key)` 返回 BYTEA，读取时用 `gs_decrypt_aes128`
2. **CHECK 与触发器协作**：触发器中 RAISE EXCEPTION 会回滚事务，额外 CHECK 做安全网
3. **连接池**：psycopg2 连接池 SimpleConnectionPool 适配 FastAPI 异步
4. **备份**：定时任务使用 APScheduler 或系统 cron，gs_dump 导出
5. **日志**：操作日志通过触发器自动写入 operation_logs 表
