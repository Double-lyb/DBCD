# 架构与环境搭建方案

## 技术选型

| 层次 | 技术 | 版本 | 说明 |
| :--- | :--- | :--- | :--- |
| 前端 | Vue.js | 3.x | 渐进式框架，易学易用，生态完善 |
| 后端 | FastAPI | 最新版 | 高性能Python Web框架，自动生成API文档 |

## 需要下载/安装的软件

### 后端环境（Python）

| 软件/库 | 用途 | 安装命令 |
| :--- | :--- | :--- |
| **Python** | 编程语言 | [官网下载](https://www.python.org/downloads/)（推荐3.9+） |
| **FastAPI** | 高性能Web框架 | `pip install fastapi` |
| **Uvicorn** | ASGI服务器 | `pip install uvicorn` |
| **psycopg2-binary** | OpenGauss/Python数据库驱动 | `pip install psycopg2-binary` |
| **SQLAlchemy** | ORM框架（可选） | `pip install sqlalchemy` |
| **python-jose** | JWT认证（可选） | `pip install python-jose[cryptography]` |

### 前端环境（Vue.js）

| 软件/库 | 用途 | 安装方式 |
| :--- | :--- | :--- |
| **Node.js** | JavaScript运行时 | [官网下载](https://nodejs.org/)（推荐18+） |
| **npm/yarn** | 包管理器 | Node.js自带npm |
| **Vue CLI** | Vue脚手架工具 | `npm install -g @vue/cli` |
| **axios** | HTTP请求库 | `npm install axios`（项目内安装） |

## OpenGauss 与 Python 连接流程

### 使用 psycopg2 连接示例

```python
import psycopg2

conn = psycopg2.connect(
    host="127.0.0.1",
    port="5432",
    database="your_db",
    user="gaussdb",
    password="your_password"
)

cur = conn.cursor()
cur.execute("SELECT * FROM your_table;")
result = cur.fetchall()

cur.close()
conn.close()
```
