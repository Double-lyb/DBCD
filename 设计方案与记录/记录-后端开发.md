### 技术点对照

| 要求 | 实现 |
|------|------|
| 模糊查询 | `GET /api/books?keyword=xxx` — ILIKE 匹配书名/作者/ISBN |
| 范围查询 | `GET /api/books?price_min=10&price_max=50` — 价格区间查询 |
| 验证码 | `/api/auth/captcha` 生成 4 位图形验证码，登录时校验 |
| RBAC | JWT payload 含 role，Depends(require_role('admin','librarian')) 拦截 |
| 密码密文 | bcrypt 哈希存入 password_hash，验证用 bcrypt.checkpw() |
| 敏感数据加密 | gs_encrypt_aes128 加密 phone/email 为 BYTEA，读取时 gs_decrypt_aes128 |
| 安全视图 | v_current_borrowings（隐藏敏感字段）、v_overdue_books（仅管理员授权） |
| 安全触发器 | 数据库层 trg_operation_log（审计）+ trg_prevent_book_delete（拦截） |
| 备份恢复 | gs_dump 全量+差异备份，backup_records 表追踪 |
| AI助手 | 多供应商路由（DeepSeek/SiliconFlow），用户上下文注入，超时重试机制 |

### 已知问题

1. **备份需要 gs_dump**：`/api/admin/backup/full` 依赖系统 PATH 中有 `gs_dump` 命令（OpenGauss 客户端工具），Docker 容器内部可用 `docker exec opengauss gs_dump ...`
2. **验证码存储**：当前使用内存 dict，服务重启后清空。生产环境应改用 Redis
3. **密码哈希不一致**：种子数据的 bcrypt 哈希为占位值，实际使用时需先通过 `/api/auth/register` 注册新用户，或使用 Python bcrypt 生成真实哈希值更新种子数据
4. **AI API 稳定性**：免费模型（SiliconFlow）响应较慢，建议使用默认的付费 DeepSeek V4 Flash
